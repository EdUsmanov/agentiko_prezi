# Аудит и тестирование

Действующее описание main, обновлено 27.09.2026. Инструкции запуска и границы воспроизводимости — [TESTING.md](TESTING.md).

## Проверки внутри генерации

- Координаты и размеры относительно canvas.
- Пересечения содержательных text/table/chart/image блоков.
- Вместимость текста по реальным метрикам TTF.
- Вместимость ячеек таблицы; один проход уменьшения размера в рамках исходной шкалы.
- Цвета и семейства шрифтов из template contract.
- Контраст текста к фону (warning).
- Количество слайдов с учётом пользовательского override.
- Наличие исходных фактов, одинаковое покрытие во всех трёх вариантах.
- Повторы наборов facts, placeholder text (warning).
- Все числа в модельном заголовке должны встречаться в соответствующем источнике.
- PPTX повторно открывается, содержит text shapes, не содержит внешних relationships.
- Число страниц PDF совпадает с планом.
- Результаты и исправления доступны в UI, manifest и ZIP.
- Critic должен указать точные variant/slide/title_quote/fact_ids; локальный валидатор отклоняет замечания, приписанные несуществующим заголовкам или чужим фактам.
- Покрытие проверяется по видимым элементам. Графики проверяются по реальным подписям/столбцам; невместимые заменяются таблицей с сохранением данных.

Ошибки итогового аудита блокируют публикацию и завершают задание как `failed`; черновики и диагностический отчёт остаются локально. `needs_review` означает доступный результат с предупреждениями или неполной дополнительной проверкой, а не одобрение дизайна. Блоки интерфейса показывают краткий статус; технические причины доступны в журнале. Некорректный модельный ответ проходит ограниченное исправление/валидацию; сбой обязательного анализа или Design останавливает задание. Автономный экстрактивный режим выбирается явно и не выдаётся за успешную работу модели.

## Автотесты

`python -m pytest -q` проверяет:

- ZIP traversal, macros, XXE;
- изоляцию явных prompt-injection строк;
- ограничения только из доверенного поля instructions;
- запрет закрытых/неописанных моделей и final без VK allowlist;
- три различных плана и одинаковое покрытие;
- PPTX native objects, отсутствие старого частного текста в XML;
- PDF с извлекаемой кириллицей и live HTML;
- неизменность подготовленного пакета;
- отказ от выдуманных fact IDs и новых чисел;
- сопоставимость единиц в диаграммах;
- отсутствие padding из повторных фактов;
- резервирование generation job и запрет позднего «успеха» после timeout;
- реальные HTTP upload/generate/download и Origin/CSP;
- принудительное завершение worker при коротком тестовом дедлайне;
- типы результатов стадий, согласованность экспортов и отсутствие циклов импортов;
- строгий replay: 429, отказ авторизации, повреждённый/усечённый JSON, ограниченное исправление схемы и кэширование только валидных ответов;
- синтетические PPTX/POTX с разной геометрией, языками и таблицами, сохранение источников и независимость макетов от имени файла.

`python -m pytest -q e2e` запускает Chromium: настоящая загрузка файлов, анализ, генерация, скачивание и чтение PPTX, история, повторный анализ через кэш, блокировка prompt injection и нейтральные сообщения при отказе провайдера. Один сценарий использует фиксированные ответы модели, два — автономную генерацию на разных входах. Скриншоты, trace, серверный лог и диагностика сохраняются в `test-results/browser/`; CI прикладывает их как `browser-evidence`.

Локальная проверка реализации `54d929c` от 27.09.2026: 670 Python-тестов, 6 браузерных сценариев, 7 проверок подписей интерфейса и Ruff прошли на macOS. Полный Python-набор выполнен четырьмя процессами примерно за 8 минут 23 секунды; браузерный — за 96 секунд. Это локальные результаты; фактический статус GitHub проверяется отдельно в [Actions](https://github.com/EdUsmanov/agentiko_prezi/actions).

`python scripts/smoke_demo.py` проверяет фактический HTTP-сервис на всех трёх проиндексированных шаблонах, по 10 слайдов × 3 варианта на шаблон. Времена и ошибки записываются в `test-results/three-templates.json`.

## Что эти проверки не доказывают

Итоги последнего ревью и исправлений — [CODE_AUDIT.md](docs/history/CODE_AUDIT.md), измерения — [TEST_REPORT.md](docs/history/TEST_REPORT.md). Ограниченный новый runtime не эквивалентен полному DeepPresenter Research/HTML/VLM продукту.

При наличии LibreOffice PDF/PNG получаются из готового PPTX; это устраняет расхождение источника предпросмотра, но само по себе не оценивает дизайн. Эти тесты не включают автоматическое сравнение с PowerPoint, OCR-совпадение, оценку качества живой VLM, полноценный adversarial eval и все браузеры/ОС. Проверка Chromium не подтверждает Safari и Firefox. Новый model-repair покрыт контрактными тестами; сетевую проверку необходимо отличать от локальной. Соблюдение font family в XML не гарантирует установленный шрифт на машине получателя.

Отсутствие ошибки геометрии не доказывает хороший сторителлинг. Семантическую обоснованность заголовков, причинных связей и рекомендаций проверяет reviewer на неизвестных примерах; API critic является вспомогательным механизмом.
