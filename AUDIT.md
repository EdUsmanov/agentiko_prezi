# Аудит и тестирование

## Проверки внутри генерации

- Координаты и размеры относительно canvas.
- Пересечения содержательных text/table/chart/image блоков.
- Вместимость текста по реальным метрикам TTF.
- Вместимость ячеек таблицы; один проход уменьшения размера в рамках исходной шкалы.
- Цвета и семейства шрифтов из template contract.
- Контраст текста к фону (warning).
- Количество слайдов с учётом пользовательского override.
- Наличие исходных фактов, одинаковое покрытие во всех трёх вариантах.
- Повторы наборов facts, placeholder text (warning).
- Все числа в модельном заголовке должны встречаться в соответствующем источнике.
- PPTX повторно открывается, содержит text shapes, не содержит внешних relationships.
- Число страниц PDF совпадает с планом.
- Результаты и исправления доступны в UI, manifest и ZIP.

При наличии ошибки состояние `needs_review`. Это доступный для диагностики результат, не успешный quality gate. В UI выводится конкретная причина. Предусмотрен экстрактивный fallback при некорректном model JSON; он явно записывается в отчёт.

## Автотесты

`python -m pytest -q` проверяет:

- ZIP traversal, macros, XXE;
- изоляцию явных prompt-injection строк;
- ограничения только из доверенного поля instructions;
- запрет закрытых/неописанных моделей и final без VK allowlist;
- три различных плана и одинаковое покрытие;
- PPTX native objects, отсутствие старого частного текста в XML;
- PDF с извлекаемой кириллицей и live HTML;
- неизменность подготовленного пакета;
- отказ от выдуманных fact IDs и новых чисел;
- сопоставимость единиц в диаграммах;
- отсутствие padding из повторных фактов;
- резервирование generation job и запрет позднего «успеха» после timeout;
- реальные HTTP upload/generate/download и Origin/CSP;
- принудительное завершение worker при коротком тестовом дедлайне.

`python scripts/smoke_demo.py` проверяет фактический HTTP-сервис на всех трёх проиндексированных шаблонах, по 10 слайдов × 3 варианта на шаблон. Времена и ошибки записываются в `test-results/three-templates.json`.

## Что эти проверки не доказывают

Не выполнены: автоматическое сравнение со скриншотом PowerPoint/LibreOffice, OCR-совпадение, VLM-оценка, полноценный adversarial eval с обфускацией/изображениями, реальные LLM latency/quality, все браузеры/ОС. PDF-предпросмотр проверяет общую сцену, но не layout engine PowerPoint. Соблюдение font family в XML не гарантирует установленный шрифт на машине получателя.

Отсутствие ошибки геометрии не доказывает хороший сторителлинг. Семантическую обоснованность заголовков, причинных связей и рекомендаций проверяет reviewer на неизвестных примерах; API critic является вспомогательным механизмом.
