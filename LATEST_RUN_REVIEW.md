# Разбор последнего пользовательского прогона

Исходный прогон: `e6a6226c8b144e75b14749aa13024bd3`, пакет
`4e36a2e34f3c410fb6a9d4a7150858da`. Старые результаты не изменялись.

## Найденные причины

1. `needs_review`, одна ошибка: VL-проверка обнаружила разрыв длинного слова
   «Официальные» внутри заголовка таблицы (analytical, слайд 9). Проверка
   вместимости считала перенос внутри слова допустимым и не учитывала запас
   ширины жирной строки. Извлечение цветов само по себе эту ошибку не исправляет.
2. Два VL-предупреждения: подпись графика (executive, слайд 4) и последний пункт
   списка (analytical, слайд 2) попадали на орнамент. Формально они оставались
   внутри текстового плейсхолдера, но тот пересекал декоративную картинку.
   Прозрачные таблицы не решают эту геометрическую проблему.
3. Общий `model_degraded`: в подготовительном анализе не завершился один
   пример организаторов (WorkSpace), хотя план пользовательского материала
   был создан моделью. Контекстуальный и визуальный аудит самого результата
   выполнялись, поэтому сообщение «модельный путь не полностью» нельзя читать
   как «VL не запускалась».

## Исправления

- Табличный аудит и подбор макета проверяют ширину целых слов и жирный заголовок.
  Размер корректируется только в доступной типографической шкале.
- По очищенному рендеру фона уточняется безопасная область тела. Новая геометрия
  используется при выборе макета и размещении текста/графиков.
- В нативных таблицах без исходной заливки отсутствует искусственная сплошная
  подложка. Если заливка исходной таблицы определена, сохраняется её alpha.
- Организаторская библиотека публикуется только после полного анализа всех
  примеров. Неполное поколение не попадает в пользовательское задание. Для
  неполного ответа классификатора есть один ограниченный повтор с точными ID.
