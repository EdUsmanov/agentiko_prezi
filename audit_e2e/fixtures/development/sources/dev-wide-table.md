## Column definitions
Requests and Closed are case counts for one week. Median hours is elapsed time per closed request. Staff FTE is scheduled staffing expressed as full-time equivalents. Reopen rate is reopened cases divided by closed cases, in percent.
## Source and limits
The DEMO IDs are fictional row labels. The snapshot has no cost, satisfaction, or backlog-age field, so it cannot support conclusions about those measures.
## Comparison rule
Compare the same week across regions only for the displayed measures. The source does not describe differences in case mix or staffing coverage.
