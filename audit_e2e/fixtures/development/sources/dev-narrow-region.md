# Archive Intake Process Note
## Overview
This fictional process note covers archive intake and exception handling.
## Purpose
This process note describes a fictional archive intake workflow. The long paragraphs are included to stress text fitting in a narrow content region.
## Receipt and first check
When a package arrives, the intake clerk records the delivery date, the sending office, and the number of containers before opening any container. The clerk checks whether the package includes a transfer list and places a temporary identifier on each box. If a list is missing, the clerk records that fact and keeps the package in the review queue until the sending office responds.
## Description and restriction review
An archivist compares the container labels with the transfer list, then records a brief description of each series. The review also checks whether a donor agreement, privacy restriction, or handling condition accompanies the material. A restriction is recorded with its exact wording and review date; the clerk does not infer an end date when the agreement is silent.
## Location assignment
After the description is checked, the records manager assigns a shelf location and updates the location register. Oversize items receive a separate location entry because they are stored in a different room. The register records the identifier, shelf, date, and staff initials so another worker can trace a later move.
## Exception handling
Damaged containers, missing lists, and uncertain ownership go to the exception queue. Staff attach a note describing what they observed and who needs to answer the question. The workflow does not permit staff to discard material while an ownership question remains open.
## Completion record
The intake is complete when the description, restriction review, and location entries are all present. The source note defines no target processing time and gives no annual intake volume, so those measures cannot be inferred from this workflow.
