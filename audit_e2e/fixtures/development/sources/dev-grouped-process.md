# Shared Equipment Checkout
## Overview
A fictional workflow describes shared equipment checkout and return.
## Process overview
This fictional procedure describes how a community workshop lends shared equipment. It is a process description, not a service performance report.
## Request
The member submits an item request with a preferred pickup date. The coordinator checks that the member record is active before reserving equipment.
## Availability
The storekeeper checks the reservation board and inspects the item. If it is already reserved or needs repair, the storekeeper records the reason and offers an available date only when one is listed.
## Handover
At pickup, the member and storekeeper compare the item identifier with the checkout form. Both initial the condition field before the item leaves the workshop.
## Return
The storekeeper checks the returned item against the checkout form and records any missing parts or damage. The member receives a copy of the return note.
## Closeout
The coordinator closes the reservation after the return record is filed. The source defines no loan duration or late-return fee.
