# Forma — Presentation Studio

Локальный open-source прототип сервиса генерации презентаций в стиле пользовательского PPTX. Python 3.11+, FastAPI, нативные объекты PowerPoint, общий формат сцены для PPTX/HTML/PDF. Интерфейс на русском, без внешних CDN и сборки frontend.

## Что уже работает

- Анализ masters, layouts, обычных слайдов и вложенных групп; извлечение шрифтов, палитры, типографической шкалы, текстовых зон и повторяющихся небольших брендовых изображений.
- Предварительный анализ трёх шаблонов организаторов через CLI; отдельный профиль каждого стиля.
- Подготовка пользовательского шаблона, текста, Markdown-таблиц и ограничений в неизменяемый `PreparedPackage`.
- Три варианта с одинаковым покрытием исходных фактов, разными порядком/композицией; нативные текст, таблицы, столбчатые диаграммы из отдельных фигур.
- Два этапа: подготовка без конкурсного лимита; три презентации и все экспорты в одном задании с жёстким общим дедлайном 300 секунд.
- Детерминированный аудит, ограниченное исправление вместимости таблиц, вывод замечаний. Ошибочный результат получает `needs_review`, а не зелёный статус качества.
- PPTX, живой HTML, PDF, PNG-предпросмотр, ZIP, manifest и история запусков.
- Уточнение количества слайдов через чат создаёт новую версию подготовки. Свободные инструкции передаются модельному планировщику при его подключении.
- OpenDesign: реальные vendored craft-файлы `typography.md` и `color.md` в контексте модельного планировщика; для каждого шаблона экспортируются `DESIGN.md` и tokens. Полный daemon OpenDesign не запускается.
- Безопасный разбор ZIP/XML, изоляция подозрительных строк, запрет внешних активов, JSON-контракты, модель без инструментов, CSP, происхождение фактов.

## Быстрый запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m studio.cli serve --port 8765
```

Откройте `http://127.0.0.1:8765`. Нажмите «Загрузить демо», выберите или загрузите PPTX, затем «Проанализировать материалы» и «Создать три презентации». Демо содержит явно вымышленные данные.

Windows: активация `.venv\Scripts\activate`; остальные команды те же. Интерфейс предназначен для настольных браузеров. В этой среде проверен Chromium, полная матрица Chrome/Firefox/Safari/Яндекс на Windows/macOS ещё не пройдена.

Индексирование трёх примеров (самих файлов в Git нет):

```bash
python -m studio.cli index-examples "/path/education.pptx" "/path/workspace.pptx" "/path/tech.pptx"
```

Можно загрузить неизвестный шаблон через интерфейс. Его палитра и шрифт не смешиваются с проанализированными примерами.

## Режимы модели

По умолчанию `STUDIO_MODEL_MODE=extractive`: весь workflow работает без сети и ключей. Этот режим раскладывает готовый исходный материал, не пишет новые факты и не заменяет LLM/VLM. Если материала меньше, чем требуется слайдов, сервис сохраняет его без выдуманного наполнения и показывает ошибку соответствия количеству. В API-режиме короткий brief может расширяться проектными тезисами: они явно помечаются «требует проверки», не допускают новых чисел и не выдаются за подтверждённые факты. Расширение происходит внутри таймера генерации. Этот модельный путь покрыт контрактными тестами, но требует реального integration run с выбранным endpoint.

Для подключения разрешённой модели создайте `.env` по `.env.example` и задайте endpoint совместимого chat-completions API. Наличие совместимого HTTP-протокола не означает использование моделей OpenAI. Ключ читается только сервером и не сохраняется в manifest.

```dotenv
STUDIO_MODEL_MODE=api
STUDIO_MODEL_BASE_URL=https://your-provider.example/v1
STUDIO_MODEL_ID=your-open-weight-model
STUDIO_MODEL_API_KEY=replace-locally
STUDIO_MODEL_PARAMETERS_B=32
STUDIO_MODEL_OPEN_WEIGHTS=true
STUDIO_MODEL_LICENSE=Apache-2.0
STUDIO_STAGE=selection
```

Перезапустите сервер. Для финала задайте `STUDIO_STAGE=final` и точный hostname VK endpoint в `STUDIO_VK_ALLOWED_HOSTS`. В финальном режиме автономный запуск запрещён. Метаданные модели подтверждает оператор, а не приложение; сверка model card и лицензии остаётся обязательной при подключении.

## Шрифты

Включён открытый Play Regular, который используется в трёх предоставленных шаблонах; лицензия находится в `fonts/OFL.txt`. Для другого шаблона скопируйте законно доступный TTF его гарнитуры в `fonts/` и перезапустите сервер. Приложение не подменяет отсутствующий шрифт чужим: подготовка остановится с объяснением. В PowerPoint на машине получателя гарнитура также должна быть установлена; встраивание шрифтов в PPTX пока не реализовано. HTML и PDF содержат используемый шрифт.

## Проверки

```bash
python -m pytest -q
# Для работающего localhost-сервиса с проиндексированными примерами:
python scripts/smoke_demo.py
```

Отчёт прогона трёх шаблонов сохраняется в `test-results/three-templates.json`. Данные, загрузки и результаты находятся в `data/`, исключённой из Git. API-документация — `/docs`.

## Границы текущей версии

- Настоящие LLM/VLM-запуски не проверены без endpoint и ключа. Экстрактивный прогон не является доказательством качества или скорости модели.
- Автоматический визуальный round-trip PPTX через PowerPoint/LibreOffice, OCR и VLM пока не подключены. PNG-предпросмотр получен из PDF той же сцены; он не доказывает идентичность отображения в PowerPoint.
- Восстановление декоративных фонов/градиентов, произвольного SmartArt, диаграмм из картинок и всех объектов сложного исходного примера неполное. Содержимое старого слайда не переносится скрыто в новый файл. Используются токены, безопасные текстовые зоны и ограниченный набор повторяющихся брендовых изображений.
- Доработка поддерживается через новый запуск с новыми ограничениями. Точечное редактирование произвольного объекта существующей презентации не реализовано.
- Генерация изображений для финала не реализована; есть зафиксированное расширение в требованиях. SmartArt необязателен согласно Q&A.
- Материал не обрезается молча. Слишком длинный текст или плотная таблица могут потребовать больше слайдов и получить `needs_review`.
- Это single-user localhost-приложение. Аутентификация, tenant isolation и публичное размещение не входят в реализованный контур. Сервер по умолчанию слушает только loopback.
- Неограниченное время подготовки не означает неограниченный размер загрузки: действуют защитные лимиты файлов и объектов.
