# Проверенный результат — 23 сентября 2026

Локальная среда: macOS ARM64, Python 3.11. Режим генерации: `extractive`, без LLM, VLM и внешнего inference. Демо-контент явно обозначен как вымышленный.

## Автоматические проверки

`python -m pytest -q`: **21 passed**. Единственное предупреждение — deprecation httpx-интеграции Starlette TestClient; падений нет. `python -m pip check`: конфликтов зависимостей нет. `compileall`: ошибок синтаксиса нет.

Проверены безопасность ZIP/XML, prompt-injection triage, запрет неподходящей модели, fact coverage, новые числа, native PPTX, кириллица PDF, XSS escaping и CSP, неизменность package, жёсткий timeout, три варианта даже для одной таблицы на одном слайде. Author для краткого brief проверен fake gateway: маркировка предложений, запрет новых чисел, неизменность исходного пакета. Это контрактные тесты, не реальный модельный прогон.

Исходные машинные отчёты: `test-results/three-templates.json`, `test-results/slides-15.json` (не входят в Git). Артефакты доступны в локальной истории запусков.

## Проверка интерфейса

Пройдено в Chromium: загрузка демо, подготовка VK Education, просмотр извлечённых токенов, генерация трёх вариантов, ссылки PPTX/HTML/PDF/ZIP, вывод аудита, последующее указание «Сделай не более 5 слайдов». Новый запуск получил 5/5/5 слайдов, исходный запуск сохранился.

Просмотрены PNG-представления светлого Education/Tech и тёмного Workspace. PPTX-файлы повторно открываются библиотекой и содержат отдельные редактируемые объекты. Попытка UI-проверки Microsoft PowerPoint прервана ошибкой захвата окна; визуальная совместимость с PowerPoint не считается проверенной.

## Непроверенное и отложенное

Реальный inference endpoint/ключ не настроен. Не проверены модельная генерация/критика, VK API, VLM/OCR, полный browser/OS matrix, визуальный round-trip PowerPoint. T2I финального этапа и точечный редактор исходного deck не реализованы. Перенос сложного декора ограничен. Подробная матрица — REQUIREMENTS.md.
