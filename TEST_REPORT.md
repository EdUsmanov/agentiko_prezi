# Проверенный результат — 23 сентября 2026

Локальная среда: macOS ARM64, Python 3.11. Проверены автономный `extractive` и реальный модельный режим NeuralDeep. Демо-контент явно обозначен как вымышленный. Внешнему inference передавались синтетические факты и стилевые метаданные, не исходные файлы шаблонов.

## Автоматические проверки

`python -m pytest -q`: **45 passed**. Единственное предупреждение — deprecation httpx-интеграции Starlette TestClient; падений нет. `python -m pip check`: конфликтов зависимостей нет. `compileall`: ошибок синтаксиса нет.

Проверены безопасность ZIP/XML, prompt-injection triage, запрет неподходящей модели, fact coverage, новые числа, native PPTX, кириллица PDF, XSS escaping и CSP, неизменность package, жёсткий timeout, три варианта даже для одной таблицы на одном слайде. Author для краткого brief проверен fake gateway: маркировка предложений, запрет новых чисел, неизменность исходного пакета. Это контрактные тесты, не реальный модельный прогон.

## Реальный inference — NeuralDeep, Qwen3.8-27B

Ключ и ID `qwen3.8-27b` проверены запросом `/v1/models` и коротким JSON-вызовом: HTTP 200, 1,98 сек. Полный первоначальный workflow занял 96,292 сек., **но это не успех модели**: planner превысил 70 сек., critic — 25 сек., файлы получены резервным экстрактивным путём.

Флаг `chat_template_kwargs.enable_thinking=false` не устранил reasoning в наблюдаемом поведении провайдера. Отдельный большой вызов с этим флагом завершился через 147,09 сек.; usage содержал 3192 reasoning-токена. Ответ декодировался как JSON, но этот диагностический вызов не доказывает прохождение всех проверок плана.

Документированный alias `qwen3.8-27b-noreason` той же модели вернул короткий JSON за 0,89 сек. и 0 reasoning-токенов. Он выбран локально для следующих сквозных прогонов:

| Шаблон | Количество | Три варианта + экспорты + текстовый critic | Резервный planner | Ошибки аудита |
|---|---|---:|---|---:|
| VK Education | 3 × 10 | 57,872 сек. | Нет | 0 |
| VK Workspace | 3 × 10 | 66,125 сек. | Нет | 0 |
| VK Tech | 3 × 10 | 70,145 сек. | Нет | 0 |

Для всех трёх запусков текстовый critic завершён. Это отдельные пакеты по три презентации, не один пакет из девяти. Подготовка исключена из таймера; генерация/экспорты/аудит включены. Единичные замеры не являются гарантией SLA на произвольных входах. Ноль ошибок текущего аудита не доказывает идеальную визуальную/смысловую точность. Образец PNG первого модельного слайда просмотрен; это не PowerPoint round-trip.

После этих замеров внутренний потолок planner увеличен с 70 до 120 секунд: наблюдаемый вызов VK Tech занял 67,454 сек., то есть запас был слишком мал. Резерв 60 секунд на оставшуюся работу и родительский общий дедлайн 300 секунд сохранены. Это изменение допуска времени, не обещание ускорения модели; таблица содержит фактически измеренные предыдущие прогоны.

Машинные отчёты: `test-results/model-integration.json` (первый timeout/fallback), `test-results/model-noreason-education.json`, `test-results/model-noreason-workspace-tech.json`. У каждого запуска сохранены артефакты и manifest с usage. Новые manifest также содержат длительности вызовов по стадиям и признак деградации модельного пути.

Дополнительные тесты покрывают aliases конфигурации, скрытие ключа в repr, data/system boundary, JSON-схему с точным числом слайдов и допустимыми ID, запрет переноса ключа через redirect, отклонение незавершённого ответа, `needs_review` при модельном timeout. OCR-клиент проверен через mock HTTP: контракт, отсутствие повторной платной загрузки, ограничение ответа/ожидания, валидация ID и передача OCR-текста в карантин. Реальный OCR не вызывался.

## Проверка интерфейса

Пройдено в Chromium: загрузка демо, подготовка VK Education, просмотр извлечённых токенов, генерация трёх вариантов, ссылки PPTX/HTML/PDF/ZIP, вывод аудита, последующее указание «Сделай не более 5 слайдов». Новый запуск получил 5/5/5 слайдов, исходный запуск сохранился.

Просмотрены PNG-представления светлого Education/Tech и тёмного Workspace. PPTX-файлы повторно открываются библиотекой и содержат отдельные редактируемые объекты. Попытка UI-проверки Microsoft PowerPoint прервана ошибкой захвата окна; визуальная совместимость с PowerPoint не считается проверенной.

## Непроверенное и отложенное

Не проверены author на коротком brief с реальной моделью, модельные 15 слайдов на вариант, VK API, VLM/реальный OCR, полный browser/OS matrix, визуальный round-trip PowerPoint. T2I финального этапа и точечный редактор исходного deck не реализованы. Перенос сложного декора ограничен. Подробная матрица — REQUIREMENTS.md.
