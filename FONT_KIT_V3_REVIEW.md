# Интеграция font-extraction 3 — 24.09.2026

## Что подключено

- MTX-декодер из третьей поставки коллеги, со включённой MPL-2.0 и описанием
  происхождения/локальных изменений. SHA-256 всех 38 файлов поставки совпал
  с её MANIFEST.json. Полный pyapi runtime не переносился.
- Отдельный процесс Node: stdin EOT → stdout TTF. Нет shell-команд из документа,
  сетевых вызовов декодера и передачи ключей. Таймаут 10 секунд с завершением
  процесса, ограничение V8 heap 128 МиБ; вход/выход/один типизированный буфер
  до 16 МиБ, суммарные явные выделения буферов до 96 МиБ. Это не OS RSS sandbox.
- Проверка имени семейства, реального веса OS/2 и курсива по бинарным данным.
  OOXML regular-слот больше не трактуется как гарантия веса 400.
- Google Fonts CSS API как запасной путь после проверки семейства в OFL-каталоге.
  Только фиксированные HTTPS-хосты, статический TTF, совпадающее начертание,
  подтверждённая лицензия, без редиректов и CSS unicode-range-подмножеств.
- Проверяемый по SHA-256 кэш, атомарная публикация, отсутствие сетевого запроса
  при повторном использовании корректного кэша. Существующий флаг отключения
  сетевого поиска сохранён.
- Изменения Python и JavaScript декодера инвалидируют библиотеку трёх примеров.

## Сохранённые ограничения

Не снимаются ограничения fsType, EOT RootString, XOR и EUDC. Variable/CFF/TTC
не конвертируются локально. Подмножество встроенного шрифта не становится полным
автоматически. Произвольные сайты шрифтов не используются. Fontsource и автоматическая
установка Aptos из скрипта коллеги не подключались: рекомендации касались MTX
и точного Google Fonts fallback; существующий локальный Aptos остаётся доступен.
