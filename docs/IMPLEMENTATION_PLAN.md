# Доработка VK Forma — согласованный объём

База: отдельный worktree `agentiko_prezi-backend-refactor`, `027870f` с сохранёнными локальными изменениями. SQLite, frontend и `data/v2` сохраняются. Работа выполняется без изменения исходного checkout.

## 1. Аудит и бриф

- Финальный неизменяемый аудит после автоматического ремонта, контрольная сумма снимка и проверяемых файлов.
- Выборочный ремонт: совместимый макет или читаемая диаграмма. Новое задание с `parent_generation_id`, исходный результат сохраняется.
- Повторный запрос идемпотентен; устаревший аудит, неизвестное действие и параллельный запуск отклоняются.
- Ошибка качества открывает аудит и PNG черновика. Обычная ошибка сети этого права не даёт; скачивание результатов закрыто до успешного gate.
- Краткий бриф задаётся явно. Пользователь видит и утверждает весь план и текст по `package_hash` + `draft_hash`.
- Правка брифа создаёт новый пакет без утверждения. До утверждения нет ручной или автоматической генерации.

## 2. Ресурсы шаблона

- Из исходного шаблона до очистки извлекаются допустимые иконки и отделимые плоские рамки.
- Каталог содержит происхождение, геометрию, превью, описание и теги; классификация использует существующий VLM gateway.
- Иконка подбирается автоматически по смыслу только при наличии свободного места.
- Скриншот: `plain` по умолчанию, `device` по запросу. Рамка и изображение остаются отдельными объектами PPTX.
- Слитые изображения и неоднозначные ресурсы пропускаются; обычная вставка остаётся рабочим вариантом.

## 3. Архитектура

- Тонкий HTTP → `PresentationService` → `JobRuntime` → worker → preparation/generation.
- Сервис владеет правилами утверждения и создания версий. Runtime — задачами, двумя слотами подготовки, процессами, отменой и shutdown.
- Store атомарно резервирует запуск. Завершившийся после отмены worker не может опубликовать результат.
- Типизированные версии документов, управляющие поля отдельно от диагностики. Старый несовместимый пакет требует повторной подготовки.
- После интеграции функции последовательно группируются в предметные пакеты. Прямые импорты, без совместимых реэкспортов. Рекурсивный граф проверяет циклы и границы HTTP.

## 4. Выдача и доказательства

- Основное действие — скачать PPTX. PDF, HTML, ZIP и отчёт — вторичные.
- В корне ZIP: `executive.pptx`, `analytical.pptx`, `story.pptx`; прочие файлы в подпапках. URL скачивания сохраняются.
- Автономный `evidence.html` строится из фактических артефактов и показывает происхождение, проверки, версии, длительности и ограничения.
- Реальный прогон, replay и непроверенные возможности различаются явно.

## 5. Проверки

1. Целевые тесты аудита, утверждения, ресурсов, атомарности и отмены.
2. Ruff и рекурсивный граф зависимостей; все пути версий кеша должны существовать.
3. Полный pytest после стабилизации дерева, UI-проверки и отдельный browser replay.
4. Проверка PPTX/POTX/OLE, кеша, шрифтов, истории и трёх форматов экспорта.
5. Отдельный локальный сервер для ручной приёмки.
6. Демо на трёх шаблонах и дополнительном неизвестном: реальные модельные вызовы только в согласованном бюджете. Replay подтверждает поведение программы, но не качество актуальной модели.

## Вне этого этапа

T2I полностью отложен: провайдер, зависимости и заглушки интерфейса не добавляются. Полноценный чат, отдельный OCR и восстановление слайда из изображения не входят в работу.

## Границы проверки

Тесты с фиксированными ответами подтверждают обработку HTTP, утверждение, экспорт и ошибки. Они не подтверждают качество текущей модели, соблюдение времени на реальном неизвестном шаблоне или лицензионную пригодность заменённой модели. Доказательный отчёт отражает режим исполнения конкретного запуска.

Промежуточный диагностический прогон во время параллельной реализации: 684 passed, 14 failed, 3 skipped (901 секунд). Сбои включали устаревшие точки подмены worker, проверку перезапуска при редактировании кода и тестовые наборы зависимостей кеша. Это не финальная приёмка; её результаты фиксируются отдельно после интеграции и переносов.

Итог после интеграции: **725 passed, 3 skipped**, browser **8 passed**, Ruff/граф/JS — успешно. Подробности, артефакты и границы приёмки: [отчёт проверки](VALIDATION_2026-09-28.md).
