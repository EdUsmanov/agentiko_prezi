## Остаточные ограничения

- Анализ пока выполняется в потоке: отмена защищает состояние и публикацию, но не принудительно прерывает уже выполняющийся сетевой вызов или рендер. Для жёсткой остановки нужен отдельный процесс анализа либо согласованная отмена между стадиями.
- Частично проверенные шаблоны не сохраняются как полностью готовый кэш; пересборка плана может повторять дорогие стадии анализа. Нельзя ускорять это, выдавая непроверенные результаты за проверенные.
- Разнообразие композиций и предупреждения визуального качества из предыдущего прогона остаются отдельной задачей приёмки. В этом аудите критерии качества не ослаблялись.
