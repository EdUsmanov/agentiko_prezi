## Подтверждённые причины

- Main fe2ee72e12fe4f30b7183d7ce6917a10 выдавал needs_review с 49 ошибками.
  Проверка обнаруживала дефекты, но не блокировала публикацию.
- Исходные указания на диаграммы и карточки попадали в body. Табличные
  имена повторялись отдельными фактами; общие макеты не учитывали декор master.
- PPTAgent 6bd55e8af6004c62b65b517ad92c2aab падал при механическом редактировании,
  несмотря на успешные API-вызовы. Причина скрывалась общим ValueError.
- При повторе обнаружен второй дефект: bridge игнорировал structured_output,
  и layout selector получал JSON без допустимого поля layout.
- После включения reasoning выявлены короткие тайм-ауты больших запросов
  и повторная обработка одного сценария/одинакового экспортированного текста.
- Живые серверы запускали платную пересборку библиотеки по изменяемым файлам.
- В повторном PPTAgent-прогоне таблица проходила проверку вместимости,
  но диаграмма вместе с обязательными подписями уже не помещалась. Неподходящий
  макет теперь исключается до выбора: используется настоящий renderer в памяти.
- Фоновые сборки могли бесконечно выигрывать общую API-блокировку у пользователя.
  Подтверждённое ожидание: 1056 секунд при самом запросе 22 секунды. Добавлена
  межпроцессная FIFO-очередь с приоритетом пользовательских работ и очисткой
  временных билетов завершившихся процессов по блокировке, без TTL догадок.

## Исправления

- Блокировка публикации известных ошибок; конкретные finding и traceback
  доступны через общий журнал с удалением секретов.
- Точные контракты полей → детерминированные команды → настоящий executor
  PPTAgent. 45/45 контрактов старого аварийного случая проверены в runtime
  без сети. Это не замена движка.
- Один сценарий; отдельный быстрый путь явно размеченного авторского deck.
  Словесные указания на графики/карточки — метаданные, не текст слайда.
- Нативные stacked/line/bar/column, отдельные единицы и итоги в подписях,
  сохранение всей таблицы при невозможности графика, редактируемые KPI-карточки.
- Таблицы с полупрозрачной заливкой и разделителями. Исправлен XML-дефект
  прозрачности PPTAgent: alpha ошибочно попадала в цвет границы.
- Заголовки учитывают логотипы master; вместимость проверяется до генерации.
  Увеличение числа слайдов требует подтверждения, факты не обрезаются.
- qwen3.8-27b, role-specific thinking_token_budget; отдельные финальные JSON.
- Общий контекстный аудит короткими блоками; дедупликация точного содержания.
  VLM повторно не оплачивается для одинаковых изображений и контекста.
- Устаревший процесс сервера не начинает новую библиотечную сборку.
  Макеты без изображений анализируются более крупными текстовыми блоками.
